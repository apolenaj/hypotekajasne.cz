# Phase 6 — SERP gap audit (Wave 1)

**Method:** Public Czech SERP / competitor page-type observation (Aug 2026).  
**No invented search volumes.**  
**NO FIRST-PARTY SEARCH QUERY DATA YET.**

## Refinancování hypotéky

| | |
|--|--|
| **SERP intent** | Mixed commercial + calculator: “vyplatí se refinancovat?”, splátková úspora, konec fixace |
| **Dominant types** | Broker/comparison calcs (Finance.cz, Peníze.cz, Finzi, Kurzy.cz), bank product pages |
| **Competitor strengths** | Instant savings calculator, fee fields, strong CTA to lead/compare |
| **Competitor weaknesses** | Weak source discipline on rates; little separation of model vs bank offer; thin process/docs |
| **Hypotéka Jasně angle** | Verified refinance-purpose published rates on `/sazby` + transparent total-cost framing + commercial explainer before parameter dump |

## Hypotéka pro OSVČ

| | |
|--|--|
| **SERP intent** | Eligibility + documents + paušální daň / výdajový paušál |
| **Dominant types** | Advisor blogs, comparison sites with bank tables |
| **Competitor strengths** | Detailed document lists; paušální daň explainers |
| **Competitor weaknesses** | Often invent specific bank % of turnover; stale bank tables; approval promises |
| **Hypotéka Jasně angle** | Generic underwriting honesty (bank methodologies differ) + diagnostic next step + no fabricated bank formulas |

## Hypotéka se zahraničním příjmem

| | |
|--|--|
| **SERP intent** | CZ property + income earned abroad / foreign employer / FX docs |
| **Dominant types** | Sparse; often conflated with “hypotéka v zahraničí” (buy abroad) |
| **Competitor strengths** | Occasional country anecdotes |
| **Competitor weaknesses** | Intent mix-up; thin doorways by country/currency |
| **Hypotéka Jasně angle** | One strong foreign-**income** landing; keep buy-abroad hub separate; documentation path + lead |

## Investiční hypotéka

| | |
|--|--|
| **SERP intent** | Rules, LTV, rental income, “kolik si půjčím na investiční byt” |
| **Dominant types** | News about ČNB 2026 recommendation, advisor articles, bank pages |
| **Competitor strengths** | Timely ČNB LTV 70 / DTI 7 coverage |
| **Competitor weaknesses** | Oversimplify “every second property”; weak model tools |
| **Hypotéka Jasně angle** | Primary ČNB definition (3rd+ OR rental purpose) + Investiční rentgen as unique model value |

## Americká hypotéka

| | |
|--|--|
| **SERP intent** | What it is, LTV, calculator, vs ordinary mortgage |
| **Dominant types** | Bank calculators (e.g. KB), aggregator explainers |
| **Competitor strengths** | Simple payment calculators; product LTV ranges |
| **Competitor weaknesses** | Mix ordinary mortgage rates into American product; risk of property pledge undersold |
| **Hypotéka Jasně angle** | Dedicated education + only product-verified rates; never `purpose=purchase` as American proxy |
